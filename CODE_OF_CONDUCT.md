# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and constructive, assume good intent, and keep discussions about the code and the problem – not about people. Harassment, insults and personal attacks are not tolerated in issues, pull requests or anywhere else in this project.

## Reporting

If someone behaves in a way that breaks this code, contact the maintainer through GitHub: open an issue, or – if it needs to stay confidential – use the private reporting on the [Security tab](https://github.com/cmelius/plesk-monitoring-server-Report/security) (*Report a vulnerability*) and say that it is about conduct. Reports are handled confidentially.

The maintainer may edit or remove comments, issues and pull requests that break this code, and may block people who keep doing so.
